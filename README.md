# PureOwner.com

Site statique de PureOwner, publié automatiquement depuis GitHub vers Cloudflare Pages.

## Déploiement

- Branche de production : `main`
- Commande de build : aucune
- Dossier de sortie : `.`
- Hébergeur : Cloudflare Pages
- Domaines : `pureowner.com` et `www.pureowner.com`

Chaque mise à jour poussée sur `main` déclenche un nouveau déploiement Cloudflare. Les branches et pull requests servent à générer des prévisualisations avant la mise en production.

## Fichiers locaux exclus

Les archives ZIP, le dossier `PureOwner-site/` et la bibliothèque de prompts sont des copies ou documents de travail. Ils ne sont pas publiés afin d'éviter les doublons et d'alléger le dépôt.
